# MATLAB ↔ Python diagnostic audit (MPDMP4 / OptMPNDS)

This folder is a **read-only audit** of the ZM26 Python OptMPNDS port against
the original She 2023 MATLAB. It does not modify `src/fairmoo_benchmarks/` or
the production algorithms under `experiments/zm26_reproduction/algorithms/`.

Scope for this first phase:

- problem: **MPDMP4**
- algorithm: **OptMPNDS**

Do not conclude MATLAB ↔ Python equivalence until MATLAB outputs exist and
`compare_outputs.py` has been run against them.

## Folder layout

```
debug_matlab_python/
├── README.md
├── DIAGNOSTIC_REPORT.md          ← written/updated by compare_outputs.py
├── compare_outputs.py
├── shared_inputs/                ← generated by Python; MATLAB must READ these
├── matlab/
│   ├── run_all_diagnostics.m     ← the only script you need to run
│   └── test_*.m
├── python/
├── matlab_outputs/               ← you generate these in MATLAB
├── python_outputs/               ← generated now
└── comparisons/
```

## What Python already did

From the repository root (`benchmarks_python`), with `fairmoo-benchmarks` activated:

```bash
conda activate fairmoo-benchmarks
cd /path/to/benchmarks_python
python -m experiments.zm26_reproduction.debug_matlab_python.python.run_all_python
```

That command:

1. writes deterministic CSVs under `shared_inputs/`
2. runs tests 01–11 and 13 into `python_outputs/`
3. runs 5 native stochastic OptMPNDS jobs on MPDMP4 (`N=200`, `FE=80000`) into
   `python_outputs/test_12_native_runs.csv`

Skip the slow native runs with `--skip-native` if you only need component tests.

## What you need to do in MATLAB

### 1. Working directory

In MATLAB:

```matlab
cd '<repo>/experiments/zm26_reproduction/debug_matlab_python/matlab'
```

where `<repo>` is the `benchmarks_python` folder. Example on this machine:

```text
/media/pedro/Acer/Users/pedro/Documents/Doutorado/Projeto de Pesquisa/benchmarks_python/experiments/zm26_reproduction/debug_matlab_python/matlab
```

### 2. Run this file

```matlab
run_all_diagnostics
```

That is the only script you need. It adds the original She sources, reads
`../shared_inputs/`, and writes `../matlab_outputs/`.

Optional slow native 5-run sanity (opens one figure per run):

```matlab
run_all_diagnostics(true)
```

or later:

```matlab
test_12_native_runs
```

### 3. Toolboxes / MATLAB version

| Requirement | Why |
|---|---|
| MATLAB **R2017b or newer** | `polyshape` / `nsidedpoly` in MPDMP |
| **Statistics and Machine Learning Toolbox** | `pdist2` in `polygon.EuclideanDistance` |
| No other toolboxes | GA / NDSort / MPNDS are plain MATLAB |

Mapping Toolbox is **not** required. Parallel Toolbox is **not** required.

## Design rule

MATLAB and Python never rely on `rng(1)` vs `np.random.seed(1)`. Shared CSVs
provide the same `X`, `F`, parent indices, and random arrays to both.

## Do not

- edit MPDMP problem files
- silently “fix” production OptMPNDS/2/3 during this phase
- rerun the full 18 × 4 × 30 ZM26 experiment
